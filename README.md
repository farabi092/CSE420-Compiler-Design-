# CSE420 — Compiler Design

A collection of laboratory assignments completed as part of the **CSE420: Compiler Design** course at **BRAC University**.

This repository contains assignment specifications, grammar definitions, and implementations of fundamental compiler construction concepts, including lexical analysis, syntax analysis, semantic analysis, symbol table management, and intermediate code generation.

## 📚 Lab Contents

### 🔹 Lab 1 — Lexical Analysis & Syntax Analysis

**Topics:**
- C language syntax and grammar.
- Lexical analysis and token recognition.
- Syntax analysis and parsing.
- Grammar specification for a subset of C.

**Lab Resources:**
- [C Syntax Analyzer Grammar](<LAB 1/Lab1_C_Syntax_Analyzer_Grammar.pdf>)
- [Lexical Analyzer & Syntax Analyzer Specification](<LAB 1/Lab1_spec_Lexical_Analyzer__Syntax_Analyzer.pdf>)

### 🔹 Lab 2 — Syntax Analysis & Symbol Table Generation

**Topics:**
- C language grammar and syntax analysis.
- Symbol table implementation and management.
- Symbol insertion, lookup, and deletion.
- Scope management and nested scopes.
- Tracking identifiers and their associated information.

**Lab Resources:**
- [C Syntax Analyzer Grammar](<LAB 2/Lab2_C_Syntax_Analyzer_Grammar.pdf>)
- [Symbol Table Generation Specification](<LAB 2/Lab2_spec_Symbol_table_Generation.pdf>)

### 🔹 Lab 3 — Semantic Analysis

**Topics:**
- Semantic analysis in compiler construction.
- Type checking and semantic validation.
- Scope and identifier consistency.
- Semantic error detection.

**Lab Resources:**
- [Semantic Analysis Specification](<LAB 3/Lab3-Semantic_Analysis.pdf>)

### 🔹 Lab 4 — Intermediate Code Generation

**Topics:**
- Intermediate representations in compiler design.
- Abstract Syntax Tree (AST) construction.
- Three-address code generation.
- Translation of expressions and statements.
- Intermediate code generation for control-flow constructs.

**Lab Resources:**
- [Intermediate Code Generation Specification](<LAB 4/Lab4-Intermediate_Code_Generation.pdf>)

## 🛠️ Technologies & Tools

Depending on the lab, the implementations may use:

- **C/C++** — Core implementation and data structures.
- **Flex** — Lexical analysis and tokenization.
- **Bison** — Grammar specification and syntax analysis.
- **Shell Scripts** — Compilation and execution automation.
- **Git & GitHub** — Version control and collaboration.
